# 3D-Company

## Run Company Floor

From the repository root, run `npm link` once to install the `3DCOMPANY` command on your PATH. Then run `3DCOMPANY` from any terminal. On first run it asks for your OpenRouter/OmniRoute-compatible Base URL, API key, and model, saves them locally, starts the bridge, and opens the app. Later runs reuse the saved settings. Use `3DCOMPANY --setup` to change provider settings.

See [Company Floor setup](./Company_Floor/company-floor/SETUP.md) for details.
